# PhonePe Pulse Data Visualization and Exploration

## Project Overview

The **PhonePe Pulse Data Visualization and Exploration** project uses Microsoft Power BI to analyze and visualize digital payment transactions and user data across India.

The objective is to transform the PhonePe Pulse dataset into an interactive dashboard that helps users explore transaction activity, transaction values, mobile usage, registered users, and geographic patterns across Indian states and districts.

## Objectives

- Analyze digital payment transactions across Indian states and districts.
- Visualize transaction counts and transaction values.
- Explore mobile brand usage and user distribution.
- Compare transaction activity across years and quarters.
- Track key performance indicators (KPIs) and year-over-year (YoY) transaction value growth.
- Provide interactive filters for exploring the data.

## Tools and Technologies

- **Microsoft Power BI Desktop** — dashboard development and visualization
- **DAX (Data Analysis Expressions)** — measures and KPI calculations
- **Power Query / Data Modeling** — data preparation and relationships
- **PhonePe Pulse dataset** — transaction and user data

## Dataset

The project uses six preprocessed datasets:

1. Aggregated Transaction
2. Aggregated User
3. Map Transaction
4. Map User
5. Top Transaction
6. Top User

These datasets contain information about transaction counts, transaction amounts, states, districts, quarters, years, mobile brands, and registered users.

**Dataset source:**(https://github.com/1234arashta/PhonePe-Pulse-Data-Visualization/blob/main/drive-download-20261024T144051Z-1-001.zip)

## Dashboard Features

### 1. Key Performance Indicators (KPIs)

- Total Transactions
- Total Transaction Value
- Average Transaction Value
- Total PhonePe Users
- Year-over-Year Transaction Value Growth

### 2. Transaction Analysis

- Transaction value by state
- Transaction count by state
- Transaction value by transaction type
- Quarterly transaction value trends

### 3. User Analysis

- Mobile brand distribution by user count
- Mobile brand user count by state
- Mobile brand percentage analysis
- Quarterly user growth trends
- Top states by user count

### 4. Geographic Analysis

- Transaction count across Indian states
- Registered PhonePe users across Indian states
- District-level transaction and user analysis

### 5. Interactive Filters

The dashboard includes dropdown slicers for exploring data by dimensions such as:

- Year
- Quarter
- State
- District
- Mobile brand
- Transaction type

Additional dropdown slicers are available in the report to support interactive exploration.

## Key Insights

The dashboard can be used to identify:

- States and districts with high transaction activity.
- Differences in transaction values across states.
- Transaction types contributing the most transaction value.
- Mobile brands with higher recorded user counts.
- Changes in transaction value over time.
- Geographic differences in transaction activity and registered users.

## How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report using the dropdown slicers.
4. Select different years, quarters, states, districts, mobile brands, and transaction types to examine the available data.
5. Review the KPI cards, charts, and maps to explore patterns and trends.

## Conclusion

This project demonstrates the use of Power BI, data modeling, DAX measures, interactive filtering, and geographic visualization to explore digital payment data. It provides a consolidated view of transaction activity and user distribution to support data exploration and insight generation.
